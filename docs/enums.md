# Enumeraciones

## Modalidad

Usada en `Programa` y `ProgramaRequest`.

| Valor | Descripción |
|-------|-------------|
| `PRESENCIAL` | Clases presenciales |
| `SEMIPRESENCIAL` | Clases semipresenciales (mixto) |
| `VIRTUAL` | Clases virtuales/online |

## Categoria

Usada en `Curso` y `CursoRequest`.

| Valor | Descripción |
|-------|-------------|
| `OE` | Obligatorio Específico |
| `EE` | Electivo Específico |
